## Observations

### Overall verdict

The note is useful but not safe to apply verbatim. It correctly extracts many hidden invariants from the Swift implementation, yet repeatedly labels an open experimental PR as "shipped reality," promotes iOS implementation choices to Android requirements, expands foundation into later parity work, and contains several factual errors. The safe posture is:

1. canonical TypeScript contracts and current server behavior decide wire truth;
2. Swift tests provide valuable cross-client behavioral cases;
3. Android owns its concurrency mechanism, timing, permissions, UI, and selected networking-stack details;
4. only the smallest contracts needed by the foundation enter implementation now.
